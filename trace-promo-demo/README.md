# INTAP Trace Promo Demo

Aplicación visual independiente para grabar videos promocionales de INTAP Trace.

## Alcance

- Demo de construcción: apartamento 304.
- Demo logística: pedido INT-1048 desde creación hasta entrega.
- Datos completamente simulados.
- Sin D1, KV, R2, Worker, autenticación ni APIs productivas.
- No modifica el frontend ni el backend actual de INTAP Code.

## Desarrollo

```bash
cd trace-promo-demo
npm install
npm run dev
```

## Build para Cloudflare Pages

```bash
npm run build
```

- Directorio raíz: `trace-promo-demo`
- Comando de build: `npm run build`
- Directorio de salida: `dist`
